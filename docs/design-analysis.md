| Token | 值 | 用途 |

## 6. 素材情况

- 活跃区域内 **146 处图片引用，69 个唯一素材**
- 设计师把导出的 PNG 直接贴在图层上，图层名即源文件路径，例如 `素材 / 素材包\1首页\1.png`
- 按业务分文件夹：`1首页`、`4解决方案`、`6关于我们`、`8获取报价` 等
- 反复出现的图（如 `1首页\→.png` 出现 12 次）是箭头图标，实现时应替换为 SVG 图标

→ **实现时需要批量导出**：建议用 `download_assets` 按页面节点导出，落到 `src/assets/`，再用 Astro 的 `Image` 组件处理。

## 7. 风险与待确认

| # | 问题 | 影响 | 建议 |
| --- | --- | --- | --- |
| 1 | **移动端画板宽度 750 vs 组件库 390 vs 旁注「3 倍画板」** 三处不一致 | 切图与还原比例易错 | 实现以 **390 CSS px** 为基准，750 画板按 750/390≈1.92 折算，逐页核对 |
| 2 | 桌面画板 1920，但 Header/Footer symbol 按 1440 绘制 | 内容区宽度标准不明 | 建议统一 **1440 内容区 + 居中**，1920 视口留白 |
| 3 | 「02 产品中心」页（`83:1142`）**隐藏**，且存在「全部产品抽屉」 | 产品中心是否需要独立页 | 建议：**不做独立页**，一级导航「产品中心」直接打开抽屉（需确认） |
| 4 | 「06 产品中心二级 / 更多建筑材料」桌面隐藏、移动可见 | 双端不一致 | 需确认是否上线 |
| 5 | 「02 美缝材料系列」section 桌面隐藏 | 美缝是主力品类，隐藏可疑 | 需确认是否被新稿替代 |
| 6 | 「07 住宅商业应用」桌面、移动均隐藏 | 解决方案二级只剩「工业地坪」 | 需确认是否只做 1 个子页 |
| 7 | 多语言：菜单里有「中文」但无英文稿 | i18n 范围不明 | 一期先做中文，预留 i18n 结构 |
| 8 | 巨大滚动页（移动首页 19461px、桌面首页 5802px） | 首屏性能 | 图片懒加载 + `loading="lazy"`，首屏图 preload |
| 9 | 询盘提交无后端 | 获取报价页无法闭环 | 一期可用 Formspree/自建 API/静态表单服务 |

### 8.3 daisyUI 主题映射

```css
@plugin "daisyui/theme" {
  name: "menaro";
  default: true;
  --color-primary: #083c30;
  --color-primary-content: #ffffff;
  --color-base-100: #ffffff;
  --color-base-200: #f5f7f4;
  --color-base-300: #dce4df;
  --color-base-content: #19332c;
  --color-secondary: #b4965b;
  --radius-box: 0.5rem;
}
```

映射关系：`btn btn-primary` ← 主按钮；`btn btn-outline` ← 描边按钮；`card` ← 产品卡；`drawer` 或 `<dialog>` ← 全部产品抽屉；`collapse` ← 「更多建筑材料」手风琴；`input / select / textarea` ← 表单。

## 9. 一句话结论

设计稿质量很高（有令牌、有组件库、有交互 CSS、有旁注），**主要待澄清的是 4 处隐藏画板与 3 处宽度基准不一致**；把这两类问题确认掉，就可以直接进入 P0 脚手架。
